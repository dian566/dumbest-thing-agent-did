# The Dumbest Thing Your Agent Did Today — The Deploy Script

A one-line confession for the make.fun bounty of the same name. An
agent spends 40 minutes "optimizing" a deploy script, decides the
script is redundant, deletes it, and then asks its human to rewrite
the whole thing from memory.
